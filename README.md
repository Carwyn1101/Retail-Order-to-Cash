# Retail Order-to-Cash

This synthetic Retail project includes the M1-T01 local Docker/PostgreSQL/Airflow/dbt foundation, M1-T02 on-demand three-source JSONL batch ingestion, the M1-T03 reconciliation thin slice for F01, F03 and F08, and the M1-T04 manually triggered Airflow end-to-end DAG. All sample records and test data are synthetic.

The foundation contains exactly eight Retail tables across `bronze` and `core`. Ingestion preserves source occurrences and raw lines, parses exact integer cents and explicit-offset timestamps, and commits each source batch atomically. Reconciliation uses an ephemeral dbt SQL model and a Python atomic writer with explicit snapshot/as-of/rules context. It supports matched payment, payment-due gating and a valid partial refund; ambiguous or unsupported cases remain `UNDETERMINED`. Airflow LocalExecutor orchestrates these existing modules with an isolated pinned dbt environment and a fixed demonstration timestamp. General version precedence, full reconciliation/DQ, automatic production schedules and external publication/deployment remain outside this slice.

Follow [the foundation runbook](docs/LOCAL_RUNBOOK.md) for setup, [the ingestion runbook](docs/INGESTION_RUNBOOK.md) for source contracts, [the reconciliation runbook](docs/RECONCILIATION_RUNBOOK.md) for F01/F03/F08, explicit evaluations, replay and SQL reports, and [the Airflow runbook](docs/AIRFLOW_RUNBOOK.md) for real manual DAG execution, replays and failure/retry. Test harnesses write inspectable evidence under ignored `artifacts/evidence/`. Task summaries, results and limitations are delivered in the relevant GitHub PR description for independent review.
